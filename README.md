# Task Manager

A self-hosted, single-owner task tracker for following work as it moves between
departments and people: who has it now, what stage it's in, and what happened
along the way. It supports separate workspaces (e.g. a company and a volunteer
organization) and can attach emails, WhatsApp messages and meeting minutes to
tasks, with optional short AI summaries using your own Anthropic API key.

> Status: planning. See [docs/PLAN.md](docs/PLAN.md).

## Your own copy, your own key

Each person runs their own instance. No API keys or credentials are included in
this repository; you add your own key in the app's Settings page.
